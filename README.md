# SOMNUS Product Page Prototype

A private responsive product-page prototype for SOMNUS. The repository contains a React/TypeScript Vite app and `shopify_product_somnus.liquid`, a separate Shopify Liquid product template.

## Run the prototype

```bash
npm install
npm run dev
```

Vite is configured for port 3000. Use `npm run build` to create a bundle and `npm run lint` to run the TypeScript check. Review `.env.example` for integration settings.

The Liquid file should be reviewed and tested in an unpublished Shopify theme before use on a live store.
